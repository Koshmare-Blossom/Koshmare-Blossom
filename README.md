## On GitHub and security researchers

Security researchers are getting shadowbanned on GitHub.

No warning. No notification. No violation notice. No appeal.
Just quietly made invisible overnight.

These are people who document vulnerabilities, publish PoCs,
and share their findings so that defense teams can understand
what they're up against and protect their systems accordingly.

That's not malware distribution. That's how security works.

Microsoft owns GitHub.
Connect the dots.
